- 🔗 **[License Plate Detection — YOLOv8s](https://github.com/b0o0da/license-plate-detection-yolov8)**
  Real-time detection fine-tuned on 10,125 annotated images — **99.4% precision**, **94.4% recall**, **94.5% mAP@50**, and **6.6ms inference** on a Tesla T4 GPU.

- 🔗 **[Visual-QA-Uni-Project](https://github.com/b0o0da/Visual-QA-Uni-Project)**
  End-to-end multi-modal Visual Question Answering system on 9,613 image-question pairs. Built in a 6-person team over a 3-week sprint — fuses CNN image encoders with NLP text encoders, evaluated with BLEU/METEOR, deployed as an inference endpoint.

- 🔗 **[Machine Learning Fundamentals — Applying](https://github.com/b0o0da/Machine-Learning-Fundamentals-Applying)**
  Hands-on implementations of core ML algorithms from scratch: regression, classification, ensembles & clustering.

- 🔗 **[Machine-Learning-Class-PipeLine](https://github.com/b0o0da/Machine-Learning-Class-PipeLine)**
  End-to-end ML pipeline covering data preprocessing, model training, and evaluation.

- 🔗 **[Celebrity-Face-Classification](https://github.com/b0o0da/Celebrity-Face-Classification)**
